# TorrServer OpenWrt v147-r2

Официальный **TorrServer MatriX.147** и **LuCI 3.0.0** для **OpenWrt 25.12.5 / aarch64_generic / apk**.

## Установка одной командой

Выполните через SSH от root:

```sh
wget -O /tmp/torrserver-install.sh https://raw.githubusercontent.com/BrainDeLook/luci-app-torrserver/main/install.sh && sh /tmp/torrserver-install.sh
```

Установщик скачивает оба нативных APK из этого релиза, проверяет совместимость, свободное место, SHA256 и заголовки APKv3. Он не устанавливает Docker или Entware и не изменяет firewall/VPN. Настройки и база сохраняются; существующие UCI и `accs.db` дополнительно резервируются в `/etc/torrserver-backups/ДАТА-PID` с закрытыми правами. Резервные копии содержат пароли.

`--check` проверяет совместимость без изменений. `--reinstall` переустанавливает эту же версию. `--from-dir /tmp/packages` использует заранее скачанные пакеты и `SHA256SUMS`.

### Исправление сетевой загрузки установщика

Скрипт теперь сначала скачивает файлы через официальный API GitHub (`api.github.com` → `release-assets.githubusercontent.com`), обходя недоступный `github.com`. При ошибке API пробует обычные ссылки релиза; ошибки больше не скрываются. Сторонние зеркала не используются. `--download-source api` отключает запасной маршрут через `github.com`, а `--download-only` проверяет загрузку без установки.

APK не изменились. Исправленный установщик, `SHA256SUMS` и отчёт тестов обновлены вместе; его исходный коммит записан в `INSTALLER-BUILDINFO.txt`. Проверяются имитация недоступности `github.com`, отказ API, полный отказ сети и настоящая загрузка публичных файлов через API с OpenWrt uclient-fetch. Работоспособность этого маршрута в вашей сети зависит от доступности двух указанных доменов.

## Установка вручную

Скачайте оба APK из этого релиза в `/tmp` и сверьте SHA256:

```sh
apk update
apk add --allow-untrusted /tmp/torrserver-147-r2.apk /tmp/luci-app-torrserver-3.0.0-r2.apk
```

После установки: **LuCI → Службы → TorrServer**, веб-интерфейс сервера — `http://IP-РОУТЕРА:8090`. Авторизация изначально выключена; включите её в LuCI при необходимости. Порты в WAN не открываются.

## Что проверено

- Нативная сборка APKv3 официальным SDK OpenWrt 25.12.5.
- Установка через скрипт в эмулируемом ARM64 OpenWrt с настоящими apk/procd/rpcd.
- Отказ при повреждённых APK до изменения пакетов.
- API, веб-интерфейс, авторизация, остановка, повторная установка с сохранением настроек и резервных копий, отключение и удаление.

Результаты — в `SMOKE-TEST.txt`, происхождение сборки — в `BUILDINFO.txt`. **Физический роутер и реальная скорость стриминга ещё не проверены**; статус обычного релиза не означает аппаратную сертификацию.

Поддерживается только указанная прошивка/архитектура. Пакеты не подписаны доверенным feed: SHA256 защищает от повреждения, доверие к загрузке основано на HTTPS и GitHub сопровождающего. Перед обновлением сохраните полный каталог данных отдельно; установщик резервирует только UCI и авторизацию. Старые альтернативные пакеты `torrserver-upx` / `torrserver-official` нужно удалить самостоятельно после резервного копирования.
