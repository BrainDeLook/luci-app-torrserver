# TorrServer MatriX.147 для OpenWrt 25.12.5

Первый релиз обновлённого форка: официальный TorrServer MatriX.147 и LuCI 3.0.0 в штатных пакетах APKv3 для **aarch64_generic**.

## Установка

Нужны оба пакета из этого релиза. Загрузите их в `/tmp` роутера и выполните:

```sh
apk update
apk add --allow-untrusted /tmp/torrserver-147-r1.apk /tmp/luci-app-torrserver-3.0.0-r1.apk
```

Откройте **LuCI → Службы → TorrServer**. Интерфейс самого сервера доступен по адресу `http://IP-РОУТЕРА:8090`. Авторизация изначально выключена, её можно включить и настроить в LuCI. Пакет не открывает порты в WAN.

## Изменения

- TorrServer обновлён с MatriX.142 до MatriX.147; бинарник собирается из закреплённого официального коммита.
- APKv3 собирается штатным OpenWrt SDK 25.12.5.
- Исправлена остановка procd: `--dontkill` больше не передаётся серверу.
- Формы LuCI используют стандартное сохранение и применение, проверку порта, адресов и числовых значений.
- Добавлены управление логином/паролем и русская локализация.
- Исправлены аргументы Telegram/FUSE и описание размера потока.
- Конфигурация и каталог данных сохраняются при обновлении.

## Проверки и ограничения

Перед публикацией требуется успешный CI с установкой пакетов в эмулируемый ARM64 OpenWrt 25.12.5. Отчёт `SMOKE-TEST.txt` приложен к релизу. Такая проверка не подтверждает производительность торрент-стриминга на физическом роутере или взаимодействие с VPN.

Поддерживается только **aarch64_generic / OpenWrt 25.12.5 / apk**. Другие архитектуры и IPK не выпускаются. Это самостоятельные пакеты без доверенного feed, поэтому нужен `--allow-untrusted`. Сверяйте файлы с `SHA256SUMS`.

Перед миграцией сохраните `/etc/config/torrserver` и каталог данных. Старые `torrserver-upx` / `torrserver-official` нужно удалить перед переходом, предварительно сохранив данные. Прежний `accs.db` поддерживается; новые данные авторизации в LuCI заменяют его одним пользователем.
