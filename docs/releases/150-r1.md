# TorrServer OpenWrt v150-r1

Обновление нашего пакета с **MatriX.147 до MatriX.150**: официальный сервер и встроенный веб-интерфейс из коммита `0c48c9ac78de2864f5fc9341e8caf89d355a4850`. LuCI — **3.0.0-r3**.

## Обновление / установка

Выполните через SSH от root:

```sh
wget -O /tmp/torrserver-install.sh https://raw.githubusercontent.com/BrainDeLook/luci-app-torrserver/v150-r1/install.sh && sh /tmp/torrserver-install.sh --download-source api
```

Не удаляйте предыдущий пакет и каталог данных. Установщик обновит оба нативных APK, сохранит UCI и базу; конфигурацию и авторизацию дополнительно скопирует в закрытый `/etc/torrserver-backups/ДАТА-PID`. Этот каталог содержит пароли. Полную резервную копию каталога данных делайте отдельно.

Загрузка через официальный `api.github.com` → `release-assets.githubusercontent.com` обходит недоступный `github.com`. При запуске без `--download-source api` предусмотрен запасной маршрут через обычные ссылки релиза. SHA256 и формат APKv3 проверяются до изменения пакетов. Firewall, VPN и репозитории не изменяются.

Вручную после скачивания и проверки обоих APK:

```sh
apk update
apk add --allow-untrusted /tmp/torrserver-150-r1.apk /tmp/luci-app-torrserver-3.0.0-r3.apk
```

После установки: **LuCI → Службы → TorrServer**. Адрес сервера по умолчанию — `http://IP-РОУТЕРА:8090`; при обновлении сохраняется ваш порт и состояние авторизации.

## Изменения upstream

Обновлены сервер и PWA веб-интерфейс, включая исправления кеширования торрентов, обработки субтитров, API и плейлистов. В MatriX.150 исправлены отображение iOS PWA и закрытие диалогов кликом вне окна. [Все изменения 147 → 150](https://github.com/YouROK/TorrServer/compare/MatriX.147...MatriX.150).

Сборка остаётся статической ARM64, **без GStreamer и SQLite**. Изменения GStreamer из upstream не включают транскодирование в нашем пакете. Дополнительные инструменты ffprobe/avprobe не входят в пакет.

## Проверки и совместимость

Только **OpenWrt 25.12.5 / aarch64_generic / apk**, штатный SDK и APKv3. Пакеты не подписаны доверенным feed, поэтому требуется `--allow-untrusted`; SHA256 не заменяет доверие к HTTPS и аккаунту сопровождающего.

В ARM64 OpenWrt проверяются установка опубликованного 147-r2 через реальный API, обновление до 150-r1 с сохранением порта и пароля, API, веб-интерфейс, rpcd, остановка, повторная установка, резервные копии, отключение и удаление. Проверяются недоступность основного домена, запасной маршрут и явные ошибки сети.

Отчёт — `SMOKE-TEST.txt`; происхождение сборки — `BUILDINFO.txt` и `INSTALLER-BUILDINFO.txt`. Проверка 150 на физическом роутере и производительность стриминга не подтверждены эмуляцией. Ранее установка 147 через API была подтверждена пользователем на роутере.
