# TorrServer для OpenWrt

Полноценные пакеты **TorrServer MatriX.147** и интерфейс управления LuCI для **OpenWrt 25.12.5 / aarch64_generic**.

[English](README.md) · [Скачать пакеты](https://github.com/BrainDeLook/luci-app-torrserver/releases) · [Проверки сборки](https://github.com/BrainDeLook/luci-app-torrserver/actions)

Форк [Medvedolog/luci-app-torrserver](https://github.com/Medvedolog/luci-app-torrserver). Сам TorrServer собирается из официальных исходников [YouROK/TorrServer](https://github.com/YouROK/TorrServer), без изменений серверной логики. На роутере не нужны Docker, Entware или скрипт загрузки бинарника при установке.

## Что изменено

- Обновлён сервер до MatriX.147, исходники закреплены на коммите `a86d8fa7fd4e07605f240fe69bf299392f7cb023`.
- Настоящие APKv3 через OpenWrt SDK 25.12.5 вместо универсальной упаковки APKv2.
- Служба procd с корректной остановкой через SIGTERM, перезапуском и применением UCI.
- Стандартные формы LuCI с проверкой значений и кнопками сохранения/применения/сброса.
- Настройка логина и пароля; корректная генерация `accs.db`, права `0600`.
- Исправлены ключи Telegram/FUSE и описание ограничения размера потока: это целое число байт, а не размер RAM-кеша.
- Проверка установки и работы в эмулируемом ARM64 OpenWrt перед публикацией.

## Совместимость

Сборка предназначена для **OpenWrt 25.12.5**, пакетного менеджера **apk**, архитектуры **aarch64_generic**. Другие архитектуры и старые версии OpenWrt сейчас не собираются. Проверьте `DISTRIB_ARCH` в выводе:

```sh
cat /etc/openwrt_release
```

## Установка

Скачайте из одного релиза **оба** файла: `torrserver-147-r1.apk` и `luci-app-torrserver-3.0.0-r1.apk`. Точные имена перечислены в релизе. Сверьте SHA256 с `SHA256SUMS` и загрузите пакеты в `/tmp` роутера.

```sh
apk update
apk add --allow-untrusted /tmp/torrserver-147-r1.apk /tmp/luci-app-torrserver-3.0.0-r1.apk
```

Это самостоятельные пакеты без настроенного доверенного репозитория, поэтому нужен `--allow-untrusted`. Системные зависимости ставятся из штатных источников вашей прошивки.

После установки: **LuCI → Службы → TorrServer**. Веб-интерфейс самого сервера: `http://IP-РОУТЕРА:8090`. Служба включается автоматически; авторизация изначально выключена. Пакеты не создают правила открытия портов в WAN. Адрес прослушивания и авторизацию можно настроить в LuCI.

Каталог данных по умолчанию — `/opt/torrserver`. Убедитесь, что хватает места под программу, установку пакетов и выбранный кеш. Параметры кеша настраиваются в веб-интерфейсе самого TorrServer. Поле максимального размера потока измеряется в байтах и не ограничивает RAM-кеш. Производительность зависит от роутера, доступной RAM, битрейта и числа подключений.

## Обновление с исходного проекта

Перед миграцией сохраните `/etc/config/torrserver` и каталог данных. Устанавливайте оба новых пакета вместе. UCI-конфигурация помечена как пользовательская и сохраняется при обновлении; база и настройки в каталоге данных не удаляются.

- Сохраняйте прежние `path`, порт и настройки прокси.
- Старый `dontkill` игнорируется: он мешает штатной остановке службы.
- Существующие `tg` и `fuse` передаются серверу через правильные ключи `-T` и `-f`.
- Старый `accs.db` используется, если новые учётные данные не заданы. Для управления через LuCI заполните оба поля авторизации.
- Новые учётные данные заменяют `accs.db` одним настроенным пользователем. Пароли хранятся открытым текстом в файлах с доступом только root, а не в виде хешей.
- При отключении авторизации файл с учётными данными сохраняется.
- Варианты `torrserver-upx` и `torrserver-official` здесь не выпускаются. Перед переходом с них сохраните данные и удалите старый альтернативный пакет сервера.
- Старый APKv2 может не поддерживаться пакетным менеджером вашей прошивки; не применяйте принудительное преобразование его базы пакетов.

Изменения в форме не управляют службой немедленно: используйте штатную кнопку **Сохранить и применить**. Кнопки запуска/остановки/перезапуска выполняют указанное действие сразу. Ручная остановка не выключает последующий запуск при перезагрузке или применении настроек. Для постоянного отключения снимите «Enable service» либо выполните:

```sh
uci set torrserver.main.enabled='0'
uci commit torrserver
/etc/init.d/torrserver restart
```

## Диагностика и удаление

```sh
/etc/init.d/torrserver status
ubus call luci.torrserver status
logread -e torrserver
/usr/bin/torrserver --version
```

Удаление: `apk del luci-app-torrserver torrserver`. Каталог данных сохраняется. Если он расположен на внешнем накопителе, накопитель должен монтироваться до запуска службы.

## Как проверяется сборка

GitHub Actions собирает официальный веб-интерфейс и статический ARM64-бинарник с `CGO_ENABLED=0`, затем создаёт APKv3 штатным SDK. UPX и вариант GStreamer не используются.

Далее пакеты устанавливаются в эмулируемый ARM64 OpenWrt 25.12.5. Проверяются версия, API и веб-интерфейс, rpcd, остановка службы, авторизация, повторная установка с сохранением настроек, отключение и удаление. Эмуляция не подтверждает скорость реального стриминга на вашем роутере, работу внешнего накопителя при загрузке и совместимость с VPN.

В артефакте сборки находятся пакеты, `SHA256SUMS`, `BUILDINFO.txt` с происхождением исходников, лицензия TorrServer и отчёт `SMOKE-TEST.txt`. Неуспешная сборка не публикует релиз. Локальная сборка описана в [English README](README.md#build-and-verification).

TorrServer распространяется по GPL-3.0. В исходном репозитории LuCI на момент форка не было отдельного файла лицензии; авторство и история проекта сохранены.
